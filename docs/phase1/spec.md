# Phase 1: yêu cầu

> Tổng kết lại sau khi đã làm.

Ứng dụng nền theo đề Simple Banking App: đăng ký, đăng nhập, xem số dư, chuyển khoản nội bộ, lịch sử giao dịch, đăng xuất. Đặc tả từng chức năng ở [FRS](../frs/README.md).

## Tiêu chí hoàn thành

| Tiêu chí | Tình trạng |
|---|---|
| 6 tính năng core chạy đúng | Backend đạt, giao diện đang hoàn thiện |
| Có test chứng minh chuyển tiền lỗi thì rollback | Đạt |
| Chạy được bằng một lệnh `docker compose up` | Có DB và backend, frontend đang làm |
| Có seed data, Swagger, README, `.env.example` | Đạt |
| CI báo thành công | Đạt cho backend, job frontend đang làm |
| Đã deploy được lên cloud | Chưa, chuyển sang [phase-cloud](../phase-cloud/task.md) |

Kịch bản nghiệm thu: [kiem-thu-phase-1.md](kiem-thu-phase-1.md).
